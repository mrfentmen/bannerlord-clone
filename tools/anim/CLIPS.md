## Clip notes

* **attack / shoot / hit-react / death** are extracted from the Quaternius SWAT model (CC0) and retargeted onto the shared skeleton.
* **idle / walk / run** are retargeted from the three.js Soldier.glb (MIT, Mixamo rig). `*-proc` are the procedural fallbacks with the same names; the game uses the retargeted clip when present and the procedural one when a model ships without source animation.
* **block / knockdown / crouch / aim-pose** are fully procedural: no source asset, no license to clear, bit-exact loops where marked.
* One-shot clips (attack, shoot, block, hit-react, death, knockdown) start and end in the neutral stance; death holds its final frame in the game via the last baked row.
* Root motion: locomotion loops are baked in-place (the sim drives position); one-shots keep authored root motion so falls read correctly.
