Boss order: work top to bottom. Max 4 OpenCode agents at a time. You code alongside them — no idle hands. No questions, we're AFK. Branch, commit, push. Pax merges.

Tone: gritty, real, modern America. No cartoon voices, no fantasy. Short lines — nobody wants a monologue in a firefight. Organize output in `assets/audio/voice/<category>/` with clear filenames.
