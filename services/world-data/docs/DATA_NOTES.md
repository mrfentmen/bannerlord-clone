- **Per-state physical mineral production tonnage by commodity** - mining_tonnes is NOT produced. The export carries mining_gva_fuel, mining_gva_nonfuel, mine_feature_count and the commodity mix, and each is labelled with what it actually is.
- **Full street-level road network** - The route graph is a highway-and-secondary network, not a street network. A march that should have used a residential street will not find one.
- **Rail line operating status and year opened** - An abandoned rail line routes the same as an active one. This matters only if the era decision selects historical road gating.
- **Settlement-level farmland, food production, and sanitation** - settlement food_production is an apportionment, not a measurement. settlement sanitation is a constant plus a population term, not a measurement. Both carry a source_apportionment flag so no consumer mistakes them for observed data.
- **Historical population for an earlier start year** - Ratings are for the 2020 census vintage. They are not valid for a 1950 start year until the pipeline is re-run against that decade's Census files.
